# AmmoGraph 0.25.1

Released: 2026-11-16

See the [calculation guide](shots-to-kill.md), [English screenshots](ui.md#shots-to-kill), and [cumulative changes since v0.23.6](release-notes-since-0.23.6.md).

- Remove armor class 10 from the representative armor profiles and Shots to Kill attributes.
- Remove the capped-results notice below the graph. Capped results continue to display as `100+` in tables, tooltips and details and have no numeric graph coordinate.

Compatibility: SPT 4.1.4 and later / .NET 10.

Installation: stop the SPT server and extract `AmmoGraph-0.25.1.7z` into the SPT root directory containing `SPT_Runtime`. Existing configuration files are preserved.
